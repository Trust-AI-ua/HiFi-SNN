# Pre-registration: revision-2 steps 4 to 6 (early-exit calibration, variance decomposition, factorial ablation)

Written 2026-11-17 on branch `journal-r2`, before any of the runs below. These steps do not
depend on the framing decision (framing 1, see `2026-11-17_r2_matched_far.md`). Thread
variables stay unset. Seeds 42 to 46 unless stated.

## Step 4. Early-exit calibration (no training)

**Data.** The cached prefix outputs `results/prefix_outputs/<ds>/treespike/seed_<S>/{val,test}_prefix.npz`
of the reported Tree-to-Spike models, IoT four, five seeds. The running posterior at step t is
`softmax(z_t)`, where `z_t` is the stored prefix logit (cumulative output membrane / t), as in
`scripts/early_exit_sweep.py`. Guard: the full-window argmax of each test prefix file
reproduces the stored test macro-F1 of its run record; and seed 42 must reproduce
`results/tables/tab_exit_audit_iot.csv`.

**Exit rule.** A sample exits at the first step whose confidence crosses the threshold and takes
that step's argmax; a sample that never crosses takes the full-window argmax.

**Calibrators, fitted on validation only.**
- **C1, per-step temperature.** One temperature per step, `tau_t`, minimizing validation NLL of
  `softmax(z_t / tau_t)` (bounded scalar search on log tau in [-3, 3]). Argmax is unchanged;
  only confidence changes. Sensitivity: one global temperature pooled over steps.
- **C2, per-class thresholds** on the uncalibrated confidence. For each class c, with every
  other class set to never exit, `theta_c` is the smallest value in
  {0.50, 0.60, 0.70, 0.80, 0.85, 0.90, 0.95, 0.99} whose validation exits predicting c are no
  less precise than the full-window validation predictions of c; if none qualifies, class c
  never exits. The classes are then combined into one rule.

**Operating points scored on test.** (U) uncalibrated, theta = 0.90 (the published audit);
(U-gate) uncalibrated, the published validation gate (`results/early_exit/selected_test.csv`);
(C1) calibrated confidence, theta = 0.90; (C1-gate) the validation gate of
`scripts/early_exit_sweep.py` rerun on calibrated confidence (same grid, eligibility within
1.0 macro-F1 point of the full window on validation, lowest executed SOPs); (C2) per-class
thresholds.

**Reported per dataset and seed.**
- Wrong-exit rate: the share of all test samples that cross the threshold with a wrong label,
  the audit definition of `scripts/exit_audit_iot.py`.
- Harmful exits: the share of test samples that exit before T with a wrong label while the
  full window is right.
- Exit share, mean and median exit step, executed SOP reduction against the full window.
- Test macro-F1 and FAR under the rule, and the change against the full window.
- ECE (15 bins), Brier score and NLL at t = 1, 5, 10, 20, before and after C1.

**R6 (decision).** A calibrator passes if all of the following hold:
- its test wrong-exit rate is lower than (U) on the IoT mean and on at least 3 of 4 datasets;
- its mean executed SOP reduction is at least 10% on the IoT mean, so it is not passing only by
  never exiting;
- its test macro-F1 is within 1.0 point of the full window on every dataset.

Early exit is kept only if some calibrator passes; the paper then reports the passing
calibrator with the lowest IoT-mean wrong-exit rate. Otherwise early exit is dropped from the
deployment claims, and the paper reports full-window results with the audit as the reason.

## Step 5. Variance decomposition (training)

**Systems.** Tree-to-Spike on CICIoT2023 and CICIoMT2024, with the production configuration
of each dataset's stored seed-42 record (CICIoT2023: the 20-epoch block).

**Seeds.** A new `data_seed` setting (default: equal to `seed`, so existing runs are
unchanged) controls only the dataset loader: subsample, split and scaling. `seed` controls
everything else: the XGBoost teacher, the encoder, initialization, batch order and torch and
numpy streams.
- **Arm D** (data varies): seed 42, data seeds 42 to 46.
- **Arm S** (training varies): data seed 42, seeds 42 to 46.
- The shared cell (42, 42) is run once and compared with the stored seed-42 record. Any
  difference is reported as run-to-run nondeterminism.

**Reported.** Macro-F1 and FAR for each run; the sample SD of each arm beside the published
five-seed SD (both seeds varying). The step is descriptive and has no decision rule.

## Step 6. Factorial ablation (training)

**Design.** Encoder (tree = `encoder_mode: tree`; raw = `raw_vanilla`, the conventional SNN's
latency code on raw features) x distillation (on = `a_kd 1.0, a_rank 0.3`; off = both 0) x
window (T = 20 or 25). Edge-IIoTset and CICIoMT2024, five seeds, 80 cells. Everything else is
the production configuration (`experiments/Tree-to-Spike/<ds>/config.yaml`).

**Reuse.** Three T = 20 cells exist and are reused if every configuration key other than the
factor keys equals the new cells' configuration:
- tree/on = `results/Tree-to-Spike`;
- tree/off = `results/encoder_ablation/<ds>/nokd`;
- raw/off = `results/encoder_ablation/<ds>/m8_raw`.

If a reused cell fails this check it is rerun. That leaves 50 new runs:
- raw/on at T = 20;
- all four cells at T = 25.

**Analysis.** Macro-F1 (primary) and FAR per cell, five-seed mean and SD. Main effects and the
two- and three-way interaction contrasts are computed per seed from that seed's eight cells.
They are reported as the mean over seeds with a t-based 95% interval (4 degrees of freedom).
The step is descriptive and has no decision rule.

**Queue.** One GPU, four concurrent runs, longest first (CICIoT2023 variance runs).
