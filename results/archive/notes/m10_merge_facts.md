## 1. Surrogate gradient: no contradiction inside the reported models

| Model | Surrogate | Source |
|---|---|---|
| Tree-to-Spike student | `fast_sigmoid(slope=25)` | `src/models/tree_to_spike.py:195` |
| Spiking-SSM | `fast_sigmoid(slope=25)` | `src/models/spiking_ssm.py:40,68` |
| Spiking-Griffin | `atan()` | `src/models/spiking_griffin.py:165` |
| S-xLSTM | `atan()` | `src/models/s_xlstm.py:149` |
| TASNN | its own `surrogate_beta = 5.0` | `experiments/TASNN/*/config.yaml` |

Every model the paper reports uses fast-sigmoid with slope 25. The `atan()`
surrogate appears only in Spiking-Griffin and S-xLSTM, which are not reported
here. If the text states a single surrogate for all models, restrict the claim to
the reported ones; if it states `atan`, it is describing the wrong two files.

## 2. Eq. 3: the epsilon is 1e-8 and guards the teacher distribution only

`src/training_treespike.py:137` sets `eps = 1e-8`, used as
`teacher_proba.clamp_min(eps) ** (1/tau)` before renormalising, i.e. it keeps the
temperature-softened teacher posterior away from zero. It is not added to a
denominator elsewhere in the loss. A separate `1e-12` guards the quantization
scale (`s = max|W|/127 + 1e-12`, `src/models/tree_to_spike.py`); the two are
different constants and should not be conflated in the text.

Also worth stating in the same place: the temperature is applied to the
*teacher's probabilities* as $p^{1/\tau}$ renormalised, not by dividing student
logits by $\tau$, and there is no $\tau^2$ gradient rescaling. If Eq. 3 is
written in the standard softened-logits form it does not match the code.

## 3. CSE-CIC-IDS2018 empty class

`probe` has **zero test support** (per-seed confusion matrices: normal 2,022,839;
dos 330,445; probe 0; r2l 57,225; u2r 24,433) and no model ever predicts it.

* Reported `f1_macro` averages the **four classes that occur**, because sklearn's
  default label set is the union of true and predicted labels. It is therefore
  not depressed by the empty class: for DNN-Tree seed 42, 73.12 is the mean of
  four per-class F1 values, not five.
* `balanced_accuracy` likewise averages the four present classes (73.59 for the
  same run).
* The stored `per_class` block nevertheless lists `probe` with F1 = 0 and
  support 0. Any table generated by averaging `per_class` would be 20% too low.
  The generators in `scripts/` use `f1_macro`, not that block.
* Recommended wording: state that CSE-CIC-IDS2018 exhibits four of the five
  taxonomy classes and that macro-averages are over classes present in the test
  split, with the class count in Table II reading "5 (4 present)".

## 6. Title / method mismatch

Needs the manuscript; not checkable here. The implementation is: an XGBoost
teacher supplies split thresholds and gain importances that define a fixed
time-to-first-spike encoder, and the tree is not executed at inference. A title
implying a hybrid tree+SNN *inference* path would misdescribe it.
