## Rules learned the hard way

- Never set OMP/MKL/OPENBLAS/TORCH thread variables for these runs (the XGBoost teacher
  depends on the OpenMP thread count).
- Process checks: `pgrep -u $(id -un) ...` only, and never a pattern that also matches the
  checking shell's own command line (a self-matching `pgrep -f` loops forever, and an
  unscoped one matches other users' jobs on this shared machine).
- Stop jobs by exact PID; check a lock's owner PID before removing it.
